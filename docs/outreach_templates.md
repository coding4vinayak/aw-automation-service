# Cold Outreach Templates

## Template 1: LinkedIn DM (Best for B2B)

```
Hi {name},

I noticed {business} doesn't have automated follow-ups 
for {pain point: leads / appointments / invoices}.

I built a free tool that fixes this in 24 hours.

Want me to send you a 2-min video showing how it works?

No pitch. Just thought it might help.
```

---

## Template 2: Email (Best for Local Business)

```
Subject: I fixed this for free - want to see?

Hi {name},

I was looking at {business} website and noticed 
{specific issue: no lead capture / no appointment booking / etc.}.

I built a free automation that fixes this.
Takes 24 hours to set up.

Want me to show you how it works?

No strings attached.

Best,
{Your name}
```

## Template 3: Facebook Group Post

```
Hey everyone!

I'm offering 3 FREE automation setups this week 
for local businesses.

What I'll build for you:
✅ Lead capture → Google Sheets
✅ Welcome email sequence
✅ Appointment reminders (if needed)

Takes 24 hours. No catch.

Comment "ME" or DM me if interested!
```

## Template 4: Cold Call Script

```
"Hi {name}, this is {your name}.

I help {industry} businesses automate their 
{lead follow-up / appointment booking / invoicing}.

I noticed {specific observation about their business}.

I can fix this for free as a sample project.
Takes 24 hours, no obligation.

Would you be open to a quick 10-minute chat 
to see if this makes sense for {business}?"
```

---

## Template 5: Referral Ask

```
"Hey {name},

Thanks for being a great client!

I'm looking for 2 more businesses like yours 
who could benefit from automation.

Anyone come to mind?

I'll give you $100 credit for each referral 
that becomes a client."
```

## Where to Find Clients (Free)

1. **Google Maps** - Search "dentist/restaurant/plumber + your city"
2. **Facebook Groups** - "Local Business Owners", "Small Business Network"
3. **LinkedIn** - Search by industry + location
4. **Yelp** - Find businesses with good reviews but no tech presence
5. **Instagram** - Search local hashtags
