# Complete Automation Service Checklist

## Before You Start

- [ ] Set up business email (yourname@domain.com)
- [ ] Create simple portfolio/website (free: Carrd, GitHub Pages)
- [ ] Set up PayPal/Stripe for payments
- [ ] Create LinkedIn profile optimized for automation services

## Client Acquisition

### Week 1-2: Find Clients
- [ ] Identify 20 local businesses in your area
- [ ] Send 10 LinkedIn DMs using outreach templates
- [ ] Post in 3 Facebook groups
- [ ] Send 5 cold emails

### Week 3-4: Close Deals
- [ ] Follow up with non-responders
- [ ] Offer free sample/demo
- [ ] Send proposals to interested leads
- [ ] Close 1-2 clients

## Client Onboarding

### Step 1: Discovery
- [ ] Send questionnaire (onboarding/questionnaire.md)
- [ ] Schedule 15-min call
- [ ] Identify pain points
- [ ] Recommend automations

### Step 2: Proposal
- [ ] Fill out proposal template (docs/proposal_template.md)
- [ ] Send proposal
- [ ] Follow up in 24-48 hours
- [ ] Get approval

### Step 3: Payment
- [ ] Send invoice (50% upfront)
- [ ] Confirm payment received
- [ ] Sign service agreement

## Delivery

### Step 4: Build
- [ ] Set up tools (Zapier/n8n/Python)
- [ ] Build automation from templates
- [ ] Test with sample data
- [ ] Document setup

### Step 5: Deliver
- [ ] Record training video (Loom)
- [ ] Schedule training call
- [ ] Walk client through automation
- [ ] Hand over documentation

### Step 6: Complete
- [ ] Get remaining payment
- [ ] Ask for testimonial
- [ ] Ask for referral
- [ ] Add to portfolio

## Post-Delivery

### Week 1
- [ ] Check in with client
- [ ] Fix any issues
- [ ] Ensure automation running

### Month 1
- [ ] Send maintenance offer
- [ ] Offer additional automations
- [ ] Request referral
